# It's Cheap – Shopping List & Price Comparison App

A Java application that helps users manage shopping lists and compare prices across multiple supermarkets to find the cheapest option.

This project focuses on algorithms, data structures, and clean object-oriented design.

---

## Features

- Add / edit / remove shopping list items
- Compare prices across 3+ supermarkets
- Automatically sort stores from cheapest to most expensive
- CSV/file-based data storage
- Structured product and store models
- Simple and efficient CLI/desktop interaction

---

## Tech Stack

- Java
- Maven
- OOP principles
- Collections & data structures
- Sorting algorithms
- File I/O (CSV)

---

## Architecture

- Product model
- Store model
- Price comparator service
- Sorting utilities
- Data persistence layer

---

## How to Run

### Clone
git clone https://github.com/ofxnilson/ItsCheap

### Build
mvn clean package

### Run
java -jar target/itscheap.jar
